## 清单模板（统一使用）

- 页面标识：模块 / 页面 / 基准页面
- 搜索项：字段、占位符、默认值、顺序
- 列表列：标题、顺序、格式化、空值展示
- 弹窗/抽屉：字段顺序、控件类型、新增与编辑差异
- 校验规则：必填、触发时机、错误文案
- 文案与 i18n：按钮/标签/提示是否走 i18n key
- 回归点：查询、重置、分页、新增、编辑、删除、权限按钮
- 差异说明：不一致项 + 原因 + 处理策略
