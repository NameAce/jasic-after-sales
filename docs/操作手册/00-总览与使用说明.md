# PC 管理端操作手册总览

## 1. 文档定位

本目录用于沉淀 `jasic-ui-antd` PC 管理端的操作手册，面向以下读者：

- 产品经理：快速了解当前系统按角色分工后的页面边界、可见菜单和关键流程。
- 运营人员：按步骤完成日常查询、建单、派单、接单、关闭等业务操作。
- 其它需要了解系统页面边界、角色差异和操作路径的内部人员。

本批手册明确按“主体/角色”拆分，不再写成一份所有角色混用的大手册。

## 3. 当前角色分层方式

结合当前运行环境，PC 管理端可以先按三类主体理解：

- 平台主体：偏治理与基础配置。
- 总部主体：偏总部调度、网点查看、工单总览。
- 服务网点主体：偏工单承接、派单、接单、维修处理。

在主体之下，再按岗位角色拆分具体操作手册：

- 平台管理员
- 总部管理员
- 总部维修员
- 一级服务网点管理员
- 一级服务网点派单员
- 一级服务网点维修员
- 二级服务网点管理员
- 二级服务网点维修员

## 4. 阅读顺序

首次使用建议按下面顺序阅读：

1. 先读 [01-登录与公共说明.md](./01-登录与公共说明.md)，理解登录方式、首页结构、工单页公共区域和截图说明。
2. 再按自己的主体和岗位进入对应角色手册。
3. 最后查看 [10-常见异常、FAQ 与权限差异.md](./10-常见异常、FAQ 与权限差异.md)，避免把“权限问题”误判成“系统故障”。

## 5. 编写口径说明

本批手册统一按“当前运行环境实际表现”编写，重点遵循以下原则：

- 以当前代码和当前运行页面为准。
- 以真实登录后可见菜单、可见按钮、可执行步骤为准。
- 对于历史测试记录与当前环境不一致的地方，明确写出现状，不按历史口径强行覆盖。
- 对于暂未跑通或存在前置条件的链路，写清楚卡点和处理建议。

## 6. 截图说明

所有截图统一存放在 `docs/操作手册/images/` 目录中。

截图使用原则如下：

- 优先展示真实页面的整体布局。
- 对关键流程补充弹窗、确认框、结果页截图。
- 对异常或权限差异，尽量保留“当前实际看到什么”的证据截图。

## 7. 重点提醒

本批整理过程中，已经确认当前环境存在若干“角色权限与直觉不完全一致”的现象，例如：

- 总部维修员当前账号首页可登录，但进入工单模块时页面会返回“返回首页”。
- 一级服务网点派单员当前账号进入工单页后，可以查询列表，但页面上未看到“建维修订单”按钮。
- 一级服务网点维修员当前账号除了维修处理外，当前环境里还能看到“建维修订单”按钮。
- 二级服务网点“有故障”后的维修登记链路，当前存在“必须先补录机型”的前置门槛。

这些内容都已单独汇总到 [10-常见异常、FAQ 与权限差异.md](./10-常见异常、FAQ 与权限差异.md) 中。
